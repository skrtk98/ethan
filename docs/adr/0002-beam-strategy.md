# ADR 0002: 既定の探索戦略を局所ビームにする

- 状態: 採用
- 日付: 2026-10-17

## 決定

`Strategy` インターフェースで探索戦略を差し替え可能にし、既定を `BeamStrategy` とする。

1. 候補プランが幅 B より多いときだけ、全候補を実行前に評価して並べ替える。
2. 上位から B 案ずつ並列に実行する。
3. その組で成功した案が複数あれば結果を評価し、最良の 1 案を採用する。残りの未実行案は刈り込む。
4. その組が全滅したら次の B 案に進む（バックトラック）。全滅の原因がすべて予算切れなら打ち切る。

既定値は K=3（候補数）、B=2（幅）とする。

## 理由

- 並列性と分かりやすさのバランスが良い。
- 選択肢がないときは評価を呼ばないので、LLM 呼び出しを節約できる。
- 大域 best-first や MCTS は、同じインターフェースの上に後から追加できる。

## 結果

評価の失敗は致命的にしない（スコアなしとして扱う）。評価は順位付けのための補助であり、評価だけが失敗して成功した結果を捨てるのは損失が大きいためである。
